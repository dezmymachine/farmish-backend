# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

**Read [`AGENTS.md`](AGENTS.md) first and follow it completely.** It is the canonical rulebook for every coding agent in this repo (workflow, hard rules, commands, gotchas). Then read `REDEVELOPMENT_PLAN.md`, `docs/ENGINEERING_GUIDE.md`, `docs/DOMAIN.md` and the spec for your phase in `docs/phases/`.

When asked to **review** a phase, use `docs/REVIEW_PROTOCOL.md`:
- check the review packet `docs/reviews/phase-NN.md` against the commits
- run `make ci` yourself
- report blocking findings first
